<h2 align="left">🧠 About Me</h2>

<p align="left">
👨🏻‍💻 I’ve been working as a full stack developer since 2020, specializing in web and mobile applications that combine performance, usability, and clean architecture.<br><br>

📱 Currently, I work as a mobile developer at <strong>Athlon Racing</strong>, contributing to an <strong>IoT application with real-time communication with motorcycles</strong>, used daily by thousands of users in Brazil and abroad.<br><br>

🚀 My current stack includes <strong>Ionic + Capacitor</strong> for mobile development and <strong>Node.js + Fastify</strong> on the backend. I work daily with RESTful APIs, JWT authentication, databases like <strong>MongoDB</strong> and <strong>MySQL</strong>, and cloud deployment using <strong>AWS</strong>, <strong>Render</strong>, and <strong>Vercel</strong>.<br><br>

🧩 I love solving complex problems with smart, scalable, and maintainable solutions. For me, good software is not just about functionality — it's about clarity, performance, and longevity.<br><br>

🏎️ Outside of work, I'm into cars, tech, and intense gym training — always pushing for growth and balance in every area of life.
